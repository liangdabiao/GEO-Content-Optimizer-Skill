  三、最致命的两个问题（P0，必须先修）

  1. 官网没有任何结构化数据（JSON-LD）
  AI 抓取器靠一段叫 JSON-LD 的代码理解「这页讲的是什么东西」。小米官网一页都没有——机器只能靠猜。

  2. 网页是「空壳」
  小米官网大量页面是用 JavaScript 动态渲染的，静态抓取只能拿到空模板（像只拿到了房子的外墙，没拿到家具）。我实测了小米手
  机商品页，访问后返回的全是错误页，AI 抓取器读到的近乎空白。

  ▎ 这两个问题影响 20 页中的大部分，是本期最该先修的。

  五、遇到的问题（诚实交代）

  豆包 3 题没采到。 原因不是死循环，而是脚本对豆包硬编码了 60 秒超时 + 自动重试 2 次，每题卡死要 3
  分钟。我一开始做定向重试，你提醒我「不可能需要这么久」，我排查后确认是脚本参数问题，停止重试、如实记录缺失 3
  题，没有伪造数据。
