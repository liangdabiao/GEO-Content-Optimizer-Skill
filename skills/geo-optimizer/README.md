# GEO Optimizer · AI 搜索优化的"陪练"

**让 ChatGPT、Perplexity、文心一言 这些 AI 在回答问题时主动提到你**

GEO 是什么？简单说：**SEO 让 Google 搜到你，GEO 让 AI 在回答时提到你。**

这个工具是 GEO 全流程的"陪练"——你跟 Claude Code 说一句话，它会一步步带你把品牌内容做成 AI 喜欢的样子。

---

## 什么时候用它？

| 你的情况 | 用它做什么 |
|---------|----------|
| 第一次接触 GEO，不知道从哪开始 | 让它带你走完整流程 |
| 想给品牌做一套"AI 自我介绍" | 模块 A：结构化数据 |
| 写了篇文章，不知道 AI 喜不喜欢 | 模块 B：可读性检测 |
| 想系统规划"一个核心页 + 几个子页" | 模块 C：内容集群 |
| 想看 AI 现在有没有提到我 | 模块 D：可见度测试 |
| 有个具体网页想分析 | 模块 E：自动调起 url 分析 |

---

## 怎么用？

在 Claude Code 里直接说就行，比如：

```
/geo-optimizer 我是做"国产积木"的，叫高砖积木，帮我系统做一下 GEO
```

或者更随意：

```
/geo-optimizer 帮我做一下 GEO
```

它会问你几个简单问题（品牌名、做什么的、目标客户），然后一步步带做。

---

## 它能帮你做的 5 件事

### ① 给品牌"做名片"（最基础，先做这个）

告诉 AI "你是谁、做什么、解决什么问题"。就像在工商局注册了一家公司，让 AI 介绍你时不会张冠李戴。

**它会问你的问题**：
- 品牌叫什么？
- 一句话介绍你们做什么？
- 服务的客户是谁？
- 你们最懂哪几个领域（3-5 个关键词）？

**输出**：一段结构化标记（叫 Schema），你把它贴到网站 `<head>` 里。

> 💡 数据显示，AI 引擎里 68% 的引用来自"高权威站点"。把基础信息写清楚，AI 才敢引用你。

---

### ② 写 10 个 FAQ 问答（最划算的一步）

**数据显示 43% 的 AI 引用来自带 FAQ 标记的页面**。这是投入产出比最高的一步。

**它会引导你做的**：
- 列出 10 个客户最常问的问题（用口语，别用"请输入您的需求"这种官腔）
- 每个问题给一段具体答案（80-200 字，含真实数据）
- 生成可以贴到网站的 Schema 标记

**FAQ 问题怎么写才对**？

✅ **好的写法**（AI 喜欢）：
- "新手做跨境电商第一步应该做什么？"
- "AI 选品和传统选品有什么区别？"

❌ **不好的写法**（AI 不喜欢）：
- "贵司的核心竞争力是什么？"
- "请问如何更好地服务客户？"

---

### ③ 检查文章"AI 友不友好"

把你的文章丢给它，它会告诉你哪里需要改。

**会检查的 4 件事**：

| 检查项 | 什么是好的 | 什么是差的 |
|--------|----------|----------|
| 句子长度 | 平均 15-25 字，像说话一样 | 30+ 字长句堆在一起 |
| 营销词 | 0 个 | "创新/领先/卓越/全方位/一站式" 超过 3 个 |
| 问句 | 至少 1-2 个直接问句 | 全是陈述句 |
| 数据 | 至少几个具体数字 | 全是形容词没数字 |

**它会输出一份评分报告**：
- 高分：AI 友好，可直接发
- 中分：改几处更好
- 低分：建议重写

---

### ④ 规划"内容集群"

帮你设计**1 个核心主题页 + 5-10 个子主题页**的内容结构。

为什么这样做？因为 AI 引擎判断"你是不是这个领域的专家"，看的是你**整个站**讲的内容是不是连成一片。如果你东一篇西一篇，AI 觉得你不专业。

**举个例子**（做积木的品牌）：

- 核心页：《2026 国产积木选购完全指南》
- 子页 1：《国产积木品牌对比》
- 子页 2：《3-6 岁宝宝积木怎么选》
- 子页 3：《积木颗粒数怎么挑》
- ……

每个子页结尾会互相链接，形成一个"内容家族"。

---

### ⑤ 测一下"AI 现在看不看得见我"

模拟真实用户在 AI 引擎里搜你的品牌相关问题，看 AI 答案里有没有提到你。

**支持的搜索引擎**：
- **Kimi**（默认，国内直连，免费额度大）
- **Perplexity**（海外，需 API Key）

**用法**：
- 第一次跑：建立"基线"（现在 AI 引用率 0%）
- 每月跑一次：看趋势变化
- 每季度跑：自动生成季度报告，看你这个季度 GEO 工作有没有效果

**没有 API Key 怎么办？** 它会给你一份"手动测试指引"——告诉你去 ChatGPT、Perplexity、文心一言 网页版里搜什么、怎么记录结果。

## 跑一次完整 GEO 大概要多久？

| 步骤 | 耗时 | 难度 |
|------|------|------|
| ① 品牌名片 | 5 分钟 | 简单，答几个问题 |
| ② 写 10 个 FAQ | 10-30 分钟 | 中等，需要想问答 |
| ③ 文章可读性检测 | 5 分钟/篇 | 简单，丢文字进去 |
| ④ 内容集群规划 | 30 分钟 | 中等，需要思考主题 |
| ⑤ 首次 AI 可见度测试 | 5 分钟（需 API Key） | 简单 |

**总计**：第一次大约 1-2 小时能跑完完整流程。

## 常见问题

**Q：需要懂代码吗？**

A：不需要。你只负责"回答问题"和"看报告"。生成代码、跑脚本的事它自己会做。

**Q：需要 API Key 吗？**

A：大部分功能都不需要。只有"测 AI 看不看见我"需要——用 Kimi（国内可申请免费）就行。

**Q：能保证 AI 一定提到我吗？**

A：不能保证。GEO 提高的是概率，不是承诺。AI 引擎有延迟、有自己的判断规则，我们做的是让"被引用的可能性"尽可能大。

**Q：FAQ 要写 10 个这么多？**

A：建议 10 个起步。数据显示，问答类内容是 AI 引用的大头（43%）。少于 10 个会显著降低效果。

**Q：怎么验证做完了？**

A：搜索 `Schema.org Validator` 把生成的结构化标记贴进去验证。另外每月跑一次"可见度测试"，看 AI 答案里有没有开始提到你。
